# Lähitaksi Ilmoitukset

Ilmoitustaulun demo palvelusopimusten ja osakkeiden ostoon ja myyntiin.

## Käyttö

Avaa `index.html` selaimessa. Asennuksia ei tarvita.

GitHub Pages: Settings > Pages > Deploy from branch > `main` / root.

## Ominaisuudet

- Ilmoituslista, suodatus tyypin (Ostetaan / Myydään) ja aiheen (Palvelusopimus / Osake) mukaan, sivutus
- Kirjautuminen (uusi sähköposti luo tilin)
- Uuden ilmoituksen luonti
- Omat tiedot: nimi, sähköposti, puhelin, salasanan vaihto, tilin poisto
- Omat ilmoitukset: muokkaus ja poisto

## Huomio

Tämä on esimerkki. Tilit ja ilmoitukset tallentuvat vain selaimen localStorageen, eikä salasanoja suojata. Tuotantoon tarvitaan palvelin, tietokanta ja oikea kirjautuminen.
